# pdf-grayscale-batch-converter
# PDF 批量灰度转换工具

一款高效、兼容的 PDF 批量灰度转换桌面应用，支持多线程处理、自定义参数，适配不同版本 PyMuPDF，轻松搞定 PDF 彩色转灰度需求。

## 🌟 核心功能
- 🔄 批量转换：支持单个/多个文件、整个文件夹（含子目录）批量处理
- ⚙️ 灵活配置：自定义分辨率（DPI）、线程数、输出前缀，支持覆盖已存在文件
- 🛡️ 极致兼容：适配新旧版本 PyMuPDF，支持加密/损坏文件检测，自动兼容 API 差异
- 📊 实时监控：进度条+详细日志，实时显示转换状态、内存占用、耗时统计
- 📁 目录保持：转换后自动保留原文件目录结构，便于文件管理
- 🚀 性能优化：智能分批处理+垃圾回收，低内存占用，支持大文件/多文件并行处理
