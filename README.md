# pdf-grayscale-batch-converter
# PDF 批量灰度转换工具

一款高效、兼容的 PDF 批量灰度转换桌面应用，支持多线程处理、自定义参数，适配不同版本 PyMuPDF，轻松搞定 PDF 彩色转灰度需求。

🌟 核心功能

• 🔄 批量转换：支持单个/多个文件、整个文件夹（含子目录）批量处理

• ⚙️ 灵活配置：自定义分辨率（DPI）、线程数、输出前缀，支持覆盖已存在文件

• 🛡️ 极致兼容：适配新旧版本 PyMuPDF，支持加密/损坏文件检测，自动兼容 API 差异

• 📊 实时监控：进度条+详细日志，实时显示转换状态、内存占用、耗时统计

• 📁 目录保持：转换后自动保留原文件目录结构，便于文件管理

• 🚀 性能优化：智能分批处理+垃圾回收，低内存占用，支持大文件/多文件并行处理

📋 快速开始

环境依赖

确保已安装 Python 3.6+（推荐 3.8+），执行以下命令安装依赖：

pip install -r requirements.txt

依赖清单（requirements.txt）

PyMuPDF>=1.18.0,<1.24.0

tkinter>=8.6

psutil>=5.8.0


运行方式

1. 克隆仓库到本地：

git clone https://github.com/WitTog/pdf-grayscale-batch-converter.git

cd pdf-grayscale-batch-converter

2. 安装依赖（见上方命令）

3. 直接运行主程序：

◦ Windows：python pdf_gray_converter.py

◦ Mac/Linux：python3 pdf_gray_converter.py

🎛️ 详细使用说明

1. 基础操作步骤
步骤 操作 说明 

1 选择文件/文件夹 两种方式：① 点击「📄 选择文件」：直接选择1个或多个 PDF 文件② 点击「输入文件夹」→「浏览」：选择整个文件夹（含子目录）批量处理 

2 设置输出目录 默认在输入目录下生成「PDF灰度输出」文件夹，可点击「输出文件夹」→「浏览」自定义路径 

3 配置参数（可选） - 分辨率(DPI)：72（快速）/150（默认，兼顾速度与质量）/300（高清）- 线程数：1-16（默认匹配CPU核心数，避免设过高导致卡顿）- 输出前缀：自定义转换后文件名前缀（默认gray_）- 覆盖选项：勾选后直接覆盖已存在的输出文件 

4 开始转换 点击「🚀 开始转换」，进度条显示整体进度，日志区实时反馈每个文件状态 

5 查看结果 转换完成后可点击弹窗的「是」直接打开输出目录，或手动进入设置的输出文件夹 

2. 日志操作

• 清空日志：点击「清空日志」一键清除当前日志内容

• 复制日志：点击「复制日志」将详细记录复制到剪贴板，便于问题排查

⚠️ 注意事项

• 支持格式：仅 PDF 文件（.pdf/.PDF），自动过滤临时文件（~$开头）

• DPI 范围：72-600，超出会提示输入错误

• 权限要求：输出文件夹需有写入权限（推荐选择桌面/自定义目录）

• 加密文件：无访问权限的加密文件会标记为失败，需解密后重新处理

• 大文件处理：建议降低 DPI（如72）或减少线程数（如2-4），避免内存溢出

🐛 常见问题速查

• Q：运行报错「No module named 'fitz'」？

A：确保安装的是 PyMuPDF（而非 fitz），执行 pip uninstall fitz -y && pip install PyMuPDF

• Q：运行后闪退/无界面？

A：安装稳定版本依赖：pip install PyMuPDF==1.21.0，并确保 Python 版本≥3.6

• Q：转换后文件打不开？

A：原文件可能损坏，查看日志区错误提示，确认原文件是否能正常打开

• Q：Mac 提示「tkinter 模块缺失」？

A：执行 brew install python-tk（需先安装 Homebrew），或重新安装带 tkinter 的 Python 版本

• Q：无写入权限提示？

A：更换输出文件夹（如桌面），或右键文件夹→属性→安全→允许写入权限

🛠️ 技术细节

• 核心库：PyMuPDF（高效 PDF 处理）、tkinter（图形界面）、psutil（内存监控）

• 多线程：ThreadPoolExecutor 并行处理，支持动态调整线程数

• 兼容性：自动检测 PyMuPDF 版本，兼容 get_pixmap/insert_image 等 API 差异

• 内存优化：分批处理页面+定时垃圾回收，降低内存占用
